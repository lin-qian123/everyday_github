# hbg-life-simulation

## 定位

`hbg-life-simulation` 是为中文“模拟人生/人生副本”叙事制作旁白视频的 Agent Skill，覆盖角色一致性、Edge TTS、字幕、漫画分镜、音乐与最终 MP4 质检。截至 2026-08-02 的 GitHub API 快照：项目创建于 2026-08-01，约 14 stars、2 forks，MIT。

## 用法

按 README 的安装脚本或将 skill 安装到兼容 agent 后，提供已获授权的中文故事文本，并明确横/竖屏、素材来源和图像生成服务。仓库默认以真实 TTS 时间轴组织 4--8 秒镜头，最终应运行其字幕、黑帧、静音、响度与关键帧检查，并人工检查人物、手部和手机等高风险画面。

## 原理

流程先固定主角身份锚点和故事结构，再以连续 TTS 的 VTT 时间轴驱动画面与字幕；图像/分镜经过 HyperFrames 和 FFmpeg 合成，QA 针对编码后的成片而非仅浏览器预览。它提供的是工作流约束，不证明生成图像或叙事本身真实。

## 价值

- 将角色一致性、音画同步和成片检查显式纳入生成视频链路。
- 对需要批量制作中文叙事短片的团队，提供可检查的资产与脚本组织方式。

## 风险边界

- 故事、声音、人物形象、BGM、图片和字幕均可能涉及版权、肖像权或误导风险。
- 自动 QA 通过不等于人物连续性、事实准确性或品牌合规已经通过。
- 依赖外部模型、Edge TTS、FFmpeg 等环境；成本、可用性与输出质量会变化。

## 补充建议

使用虚构或已授权素材做小样，建立人物和音乐来源台账；发布前增加人工事实审校、敏感内容审查与完整成片复看。
