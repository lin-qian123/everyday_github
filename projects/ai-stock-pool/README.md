# ai-stock-pool

## 定位

`ai-stock-pool` 是 AI 产业链股票池，提供美股/A 股映射、动态发现、政策压力观察和一键部署。

截至 2026-07-27，GitHub API 显示其创建于 2026-07-26，约 46 stars、25 forks；属早期行业应用信号。

## 用法

部署前先核对数据来源、更新时间、地区市场规则和任何模型生成的解释；输出仅应作为研究线索。

## 原理

把产业链实体、市场代码、新闻/政策线索和筛选规则汇成可更新的投研信息层。

## 价值

- 为跟踪 AI 基础设施和应用链条提供结构化入口。
- A 股与美股映射有助于跨市场研究起点。

## 风险边界

- 不构成投资建议；数据延迟、分类偏差和模型摘要都会影响结论。
- 需审计数据许可、回测偏差和风险披露。

## 补充建议

将其与原始财报、交易所公告和独立估值框架交叉验证，避免直接把标签当交易信号。
