## 定位

工业控制系统异常检测、攻击溯源与联动响应的早期平台。仓库包含 Vue 控制台、Python 检测服务、训练/推理代码和示例数据，目标是将流程图、PLC 点位与运行时序统一为工业时空图（ISTG）。

## 用法

先在隔离网络用示例数据启动前端与 FastAPI 服务，再上传流程/点位说明和正常时序数据构图训练。实时模式需配置对应模型、依赖图、特征顺序和测试 PLC 地址；可用 `/api/health` 检查服务，调用异步检测接口轮询结果。

## 原理

将传感器、执行器、控制器及工艺环节的物理、控制和数据依赖表示为图，并结合滑动时间窗口与图神经网络进行重构/异常评分。异常后根据依赖路径展示受影响组件与可能传播链，辅助人工溯源。

## 价值

它把 OT 场景常见的拓扑关系与多变量时序检测放在一个可视化工作台，适合原型验证、训练数据整理与告警解释的共同界面。

## 风险边界

仓库明确建议真实 PLC 接入前完成隔离网络校验。模型不能证明攻击归因；特征漂移、错误点位映射或错配 checkpoint 都会使结果失效。许可证缺失，部署、数据和第三方组件授权须另行审计。

## 补充建议

先以数字孪生/仿真 PLC 做只读采集，设置物理安全联锁与人工确认，测量误报、漏报、检测时延和故障恢复。不要将异常评分直接连接到可写控制动作。
