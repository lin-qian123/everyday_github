# oil-tone

## 定位

`oil-tone` 是一份中英双语写作 skill，试图让 AI 文案在既有材料边界内更直接、完整、可读，重点压制空泛标题、无信息结尾和含糊动作描述。

截至 2026-07-28，GitHub API 显示其创建于 2026-07-27，约 36 stars、3 forks；属于早期开发者信号。

## 用法

安装或复制 `skills/oil-tone/` 后，在写作、改稿或 PPT 文案任务中显式调用该 skill；对已完成文稿可先运行随附的 `tone_lint.py`，再进行人工通读。

## 原理

它把一组风格偏好写为可加载指令，并附带基于已知模式的标准库 Python 检查器。指令负责语境化改写，脚本只发现可确定识别的表达模式。

## 价值

- 对中文产品说明、博客和演示稿，能把“有态度但没信息”的惯性语言变成可检查的改稿项。
- 把文风规则与检查脚本放在版本控制中，便于团队讨论与渐进修正。

## 风险边界

- 风格偏好不是事实核验；它不能证明主张、因果或第一人称经历真实。
- 机械压缩可能删掉必要的背景、风险提示或情感表达，不能把 lint 通过当成发布许可。
- 安装外部 skill 前仍需审计其脚本与后续更新内容。

## 补充建议

先在有原始材料和评审标准的样稿上 A/B 对比；把团队确实认可的规则留下，并为专业术语、合规说明和品牌语气设置明确例外。
