# fingertips

## 定位

`fingertips` 是给对话型 AI 加入“输入节奏”信号的轻量组件：它记录打字时长、停顿、正在输入与未发送输入等时间模式，声明不上传文本内容，再把摘要注入模型上下文或触发关怀消息。

截至 2026-07-30，GitHub API 显示仓库创建于 2026-07-29，约 47 stars、6 forks，MIT 许可证；它是早期开发者信号，情绪推断效果未获本仓库外的独立验证。

## 用法

把项目的前端探针接到输入框，后端用 `RhythmStore` 接收 ping；消息发送时再读取摘要。`watcher.py` 是可选轮询器，可能主动触发外发消息，因此应先关闭或接到测试通道。

```python
from fingertips import RhythmStore

store = RhythmStore()
# 输入事件：store.ping()
# 发消息前：note = store.pop_note()
```

## 原理

前端以固定间隔报告“仍在输入”的事实，后端仅维护时间戳和间隔，并以阈值计算长输入、暂停或“欲言又止”摘要。这样避免把文字本身交给该组件，但节律仍可能构成敏感行为数据。

## 价值

- 给陪伴式或辅助式交互提供比最终文本更早的、低带宽的上下文信号。
- 将内容最小化写进数据结构，而不是仅依赖提示词约定。

## 风险边界

- 键盘动力学可被用于身份、压力或情绪相关推断；“不采内容”不等于无需同意、告知、保留期限和删除机制。
- 由停顿触发的主动消息可能造成打扰或误判，绝不可用于医疗、危机干预、雇佣或高风险决定。
- README 引用的情绪相关研究不能直接证明这个具体实现的准确率、因果性或适用人群。

## 补充建议

默认采用明确 opt-in、最短保留、端侧处理和一键删除；在上线前用不同输入习惯测试误触发率，并让用户能查看、关闭与撤回节律摘要。
