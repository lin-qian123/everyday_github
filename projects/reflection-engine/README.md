# reflection-engine

- 仓库：[kropdx/reflection-engine](https://github.com/kropdx/reflection-engine)
- 快照：2026-08-04；创建于 2026-08-03，约 36 stars、3 forks；GitHub API 未给出 SPDX 许可证。
- 分类：记忆层与个人 AI 基础设施

## 定位

一个可下载的单 Markdown prompt，要求支持长期记忆的 AI 助手基于既有聊天、记忆与用户上传材料生成带证据与置信度的个人反思画像，并给出每周可尝试的行动。

## 用法

在确实拥有所需对话上下文的个人账号中，先确认历史引用和记忆设置，另开新会话上传 `Reflection-Engine-v1.3.md` 后按 README 指示执行。输出应保存在私有位置，而非共享工作区。

## 原理

它不是独立服务，而是把“列出证据、评估反证、标注置信度、给出具体行动”的问题框架交给当前模型。结果质量取决于模型实际可见的语料、检索能力和是否遵从该框架。

## 价值

为个人使用提供一种有结构的回顾入口：它避免将模糊印象包装成确定结论，并鼓励把一项可试验行动和证据对应起来。

## 风险边界

个人聊天、健康、关系、财务和上传文件高度敏感；“没有额外服务”不等于数据风险消失，数据仍受所选 AI 提供商、账号与记忆设置约束。它不是心理治疗、诊断或专业建议，模型的归纳可能有偏差。

## 补充建议

先用经过脱敏且范围有限的材料试运行；逐条核对引用证据，明确允许模型不知道或拒答的区域。不要基于一次输出作重大医疗、财务或关系决定。
