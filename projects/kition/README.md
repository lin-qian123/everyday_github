# Kition

## 定位

`Kition` 是一个将 Markdown 文档、表格、浏览器研究、AI agent 与可视化工作流放在同一桌面工作区的开源产品。截至 2026-07-26，仓库创建于 2026-07-25，约 3 stars、0 forks，处于 beta；公开客户端采用 AGPL-3.0，需注意其运行时与服务边界。

## 用法

普通用户可从 Releases 下载 macOS 或 Windows 桌面版。源码试用需安装 pnpm 10.33.0，执行 `pnpm install --frozen-lockfile` 后运行 `pnpm dev`；仅启动 Web 界面可用 `pnpm dev:web`。先用非敏感笔记创建文档、表格和浏览器研究，再审查 agent/workflow 的模型、代理、MCP 与账号设置。

## 原理

它把文档作为互相关联的知识节点，将表格做成轻量数据工具，并通过浏览器研究给 agent 提供上下文；重复操作在可视化 trigger-action 画布中编排。桌面客户端与签名运行时结合，公开仓库并不等同于可在本地从源码重建全部运行组件。

## 价值

- 让研究笔记、结构化数据、浏览器资料与自动化不必分散在多套工具中。
- 为“给 agent 可追踪上下文”提供了比单一聊天窗口更接近工作台的界面。
- 已提供桌面安装入口，适合先用小规模个人流程验证。

## 风险边界

- 仅有早期 star 信号，不能据此推断稳定性、用户规模或长期维护能力。
- AGPL-3.0 对嵌入、再分发与网络服务有合规影响；签名运行时也意味着不能假定完整离线可复现。
- 浏览器研究、模型代理与 MCP 可能接触文档或账号数据，应逐项确认数据去向和权限。

## 补充建议

先建立隔离测试工作区，关闭不必要的远程模型、MCP 与浏览器登录态；用导出、备份、跨设备同步和离线恢复测试判断是否可承载正式知识库。团队采用前还应审查 AGPL 义务及公开/闭源运行时边界。
